# 🟢 Binary Parser

A simple web tool to **perform text–binary conversions**.

---

## ✨ What it does

- Convert **Text → Binary** and **Binary → Text**.
- Visualize how characters are stored in binary using the ASCII table.
- 100% client-side – everything runs in your browser.

---

## 🚀 How to use

1. Choose the conversion mode:

   - `Text → Binary`
   - `Binary → Text`

2. Enter your message in the input field.
3. Click **Generate**.
4. Check the result in the _Converted message_ section.

---

## 🧪 Examples

- **Text → Binary**

  ```
  A
  ```

  ➡️ `01000001`

- **Binary → Text**

  ```
  01001000 01101001
  ```

  ➡️ `Hi`

---

## 📚 Quick Theory

- Computers only understand **binary (0 and 1)**.
- Each letter or symbol is mapped to a number using standards like **ASCII** or **Unicode**.
- That number is then written in binary, which is how it’s stored in memory.

So when you type `"A"`, the computer sees `65` in ASCII, which becomes `01000001` in binary.
